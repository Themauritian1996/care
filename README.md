# Care

**C**roissance · **A**ctivité · **R**endez-vous · **É**veil
*Childhood · Activity · Routines · Evolution*

Carnet de suivi de l'enfant, de la naissance à 18 ans : quotidien et bien-être, courbes OMS et projection de taille, jalons du développement, vaccins du PIQ, agenda, conseils selon l'âge.

- **Site web** : publié automatiquement sur GitHub Pages.
- **APK Android** : compilé automatiquement à chaque modification. Téléchargez `Care.apk` dans l'onglet *Releases*.

Les données restent sur l'appareil (stockage local). Utilisez *Plus > Mes données* pour faire une sauvegarde.
